## ja

右側の「ダウンロード」タブで、画像全体か画面に映っている範囲かを選び、IIIF Image API が提供する大きさから選んで保存できます。画像サーバが提供できない大きさは出しません。動画・音声・3D モデルは、マニフェストが指すファイルを保存できます。

## en

In the new Download tab, choose the whole image or the part on screen, pick one of the sizes the IIIF Image API offers, and save it. Sizes the image server cannot serve are not listed. For video, audio and 3D models, the file the manifest links can be saved.

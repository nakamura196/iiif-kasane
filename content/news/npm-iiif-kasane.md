## ja

Kasane のビューアを、npm install iiif-kasane で入れられるようになりました。これまでの @nakamura196/iiif-viewer は名前を改めたもので、import の名前を iiif-kasane に替えれば、ほかはそのまま使えます。

## en

You can now install Kasane's viewer with npm install iiif-kasane. It is the package formerly named @nakamura196/iiif-viewer: change your imports to iiif-kasane and nothing else needs to change.

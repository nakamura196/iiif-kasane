# 画像が出るまでの時間

遅い画像サーバ（HTTP/1.1、1 回 0.4〜0.9 秒）で、ビューアが何をどの順に取っているかを測り、縮める。

## 2026-10-23 東京大学の画像サーバで測る

- 資料: 東京大学附属図書館の源氏物語（88 コマ）。マニフェストは `da.dl.itc.u-tokyo.ac.jp`、画像は `iiif.dl.itc.u-tokyo.ac.jp`
- 測り方: Chrome で本番（kasane.ldas.jp）を開き、Resource Timing（`performance.getEntriesByType('resource')`）で
  取得の開始と終了を並べた。キャッシュに無いコマ（31 コマ目）を開いた。測った場所はバンクーバー
- 窓は幅 3,008 CSS ピクセル、devicePixelRatio 2。このため最初の 1 画面で原寸のタイルが要る（下の 130 枚）。ふつうのノートの幅なら枚数は減る
- curl での単体: kasane の画面 0.05 秒、マニフェスト（97KB）0.8 秒、info.json もタイルも 1 回 0.4〜0.9 秒

| 時刻（秒） | 取得 |
|---|---|
| 0.26–1.13 | マニフェスト 2 本（ページ側の ViewerContent と useManifest） |
| 1.43–1.75 | 同じマニフェストをもう 1 本（画像の表示の useRawManifest）。これが済むまで画像の取得が始まらない |
| 1.94–2.47 | info.json |
| 2.82–3.87 | ページ全体の画像（`full/1661,`）。絵が出るのはここ |
| 2.82–11.3 | タイル 512 四方を 130 枚。全部そろうまで約 8 秒 |

- 全コマの縮小画像を最初に取る動きは無かった。縮小画像（`!220,220`）は表紙と今のコマの 2 枚だけ（右の情報パネル）
- HTTP/1.1 なので同じホストに同時 6 本。ページ全体の画像とタイル 130 枚を同時に頼んでいて、
  全体の画像が行列の先頭に入ったのはたまたま
- マニフェストのサーバは参照元が `localhost` だと 403 を返す（curl で Referer を付けて再現）。手元で確かめるときは、
  マニフェストの写しを `public/` に置いて開いた

## 2026-10-23 直したこと（iiif-viewer 0.1.5）

- `fetchManifest`（core/services/utils.ts）: 同じ URL の取得を 1 本にまとめ、結果を 60 秒覚える。失敗は覚えない。
  60 秒にしたのは、編集中の取り直しを妨げないことと、Collection で多数のマニフェストを開いたときに覚えすぎないため
- `ImageTiles.tsx`: タイルはページ全体の画像が来てから（または失敗してから）頼む。全体の画像に `fetchPriority="high"`。
  タイルは見えている範囲の真ん中に近いものから並べる（ブラウザはこの順に頼む）
- 手元（マニフェストは `public/` の写し、57 コマ目）で測った順番: マニフェスト 1 本 → 0.12 秒後に info.json →
  その 3 ミリ秒後に全体の画像 → 全体の画像が届いてからタイル 130 枚（真ん中から）
- 本番に当てはめた見積もり: マニフェスト 1.13 秒 → info.json 〜1.7 秒 → 全体の画像 〜2.7 秒（直す前 3.9 秒）
- 確かめていないこと: 本番に配ってからの実測。タイル 130 枚がそろうまでの約 8 秒は変わらない
  （一段粗いタイルから頼めば枚数は 4 分の 1 になるが、今回は入れていない）

## 2026-10-23 本番に配ってから測り直す（#282・#285 の後）

- 測り方: Playwright（ヘッドレスの Chromium、devicePixelRatio 2）で本番を開き、前と同じく Resource Timing を並べた。
  コマごとに新しいブラウザの文脈（キャッシュ無し）で、まだ開いていないコマを選んだ。測った場所はバンクーバー、
  Mac のロードアベレージ 10〜13（16 コア）
- 前回は手元の Chrome（画面あり）で測ったので、条件は完全には同じではない

- 絵が出るまで 2.3〜2.7 秒。直す前の 3.9 秒から約 1.3 秒縮み、見積もり（約 2.7 秒）どおりか少し速い
- マニフェストは 1 本だけ。info.json はマニフェストの直後、全体の画像は info.json の直後、
  タイルは全体の画像が届いてから始まっている（設計どおりの順）
- タイルがそろうまでは、広い窓（130 枚）で 7.7〜10.6 秒、ふつうのノートの幅（35 枚）で 4.9〜5.4 秒。
  ここは変わっていない。縮めるなら、一段粗いタイルから頼む案（未着手）
- 測りに使ったスクリプトは残していない（Playwright で上の値を出すだけの 40 行ほど）

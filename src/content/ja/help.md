# ヘルプ

IIIF Kasane は、IIIF のマニフェストを読み込んで、資料を表示するビューアです。3D モデル・画像・音声・動画と、それに付いた注釈（アノテーション）を、一つの画面に重ねて表示します。このページでは、資料の開き方、画面の見方、操作のしかた、うまく表示できないときの確かめ方を説明します。

## 資料を開く

### マニフェストの URL を入れる

トップページの入力欄に、IIIF マニフェストの URL を入れて「表示する」を押します。ビューアの画面が開き、資料が表示されます。

Presentation API 4.0（草案）と 3.0 のマニフェストを表示できます。2.0 のマニフェストも、読み込むときに新しい形に変換して表示します。

コレクション（Collection）の URL を入れると、収録された資料の一覧が出ます。一覧から資料を選ぶと、その資料が開きます。資料に日付（navDate）が付いていれば、年代順に並べ替えたり、年表で見たりできます。

### サンプルとユースケースから開く

すぐに試したいときは、用意した例から開けます。

- [ユースケース](../usecases/): 実際の資料で Kasane を使った例です。動画で使い方を見てから、「Kasane で開く」で同じ資料を開けます。
- [サンプル一覧](../samples/): IIIF Cookbook のレシピと、このサイトの検査用のマニフェストです。画像・音声・動画・3D に分けて並べています。「ビューアで開く」で、表示できるかを確かめられます。

### URL で直接開く

ビューアの URL に、開く資料を書き込めます。リンクを作って人に渡すときや、論文・ウェブページから資料を指すときに使います。

- `/ja/viewer/?iiif-content=<マニフェストの URL>` で、その資料を開きます。
- `iiif-content` には、IIIF Content State（資料の中の場所を指すための IIIF の規格）も書けます。ページ・画像の領域・音声や動画の時刻を指していれば、その場所を開いて目立たせます。複数のページを指していれば、並べて表示します。
- `&canvas=3` のように足すと、3 ページ目から開きます。数は 1 から数えます。ページの URI（Canvas の id）でも指定できます。
- `&tab=map` のように足すと、右の説明欄でそのタブを選んだ状態で開きます。
- 以前の形の `?manifest=<URL>` も使えます。IIIF Curation Viewer と同じ `?curation=<URL>` と `&pos=<番号>` も読みます。

### 比較の画面を URL で開く

比較の画面（`/ja/compare/`）では、別々の資料の画像を見比べられます。所蔵機関の違う資料どうしでも構いません。

- `?src=<URL>&src=<URL>` のように、`src=` を比べたいものの数だけ繰り返します。URL には、マニフェストか、画像 1 枚の info.json（IIIF Image API の画像情報）を書きます。混ぜても構いません。
- コレクションは `?iiif-content=<URL>` で指定します。収録されたマニフェストがまとめて読み込まれます。そのあとに `src=` を足すこともできます。
- 指定したものに入っている画像は、頭から順に 1 列に並びます。`&a=0&b=1` は、その列の何番目を A と B に出すかです。数は 0 から数えます。
- `&mode=` で見せ方を選びます。`side`（左右に並べる）、`swipe`（スワイプ）、`spyglass`（スパイグラス）、`overlay`（重ねる）です。スワイプの境目を横にするときは `&dir=v` を足します。
- URL は符号化して書きます（`/` は `%2F`、`:` は `%3A`）。info.json の URL に元から `%2F` が入っているときは、`%252F` になります。
- 画面の「資料」から追加・削除すると、URL の `src=` も書き換わります。比べたい組み合わせを画面で作ってから、URL をコピーして渡すのが簡単です。

例: 国立公文書館とスタンフォード大学図書館のマニフェストを、スワイプで見比べる

```
/ja/compare/?src=https%3A%2F%2Fwww.digital.archives.go.jp%2Fapi%2Fiiif%2F764297%2Fmanifest.json&src=https%3A%2F%2Fpurl.stanford.edu%2Fhs631zg4177%2Fiiif%2Fmanifest&a=0&b=1&mode=swipe
```

例: マニフェストと、画像 1 枚の info.json を見比べる

```
/ja/compare/?src=https%3A%2F%2Fwww.digital.archives.go.jp%2Fapi%2Fiiif%2F764297%2Fmanifest.json&src=https%3A%2F%2Fstacks.stanford.edu%2Fimage%2Fiiif%2Fhs631zg4177%252Fhs631zg4177_00_0001%2Finfo.json&a=0&b=1&mode=swipe
```

### リンクを落として開く

資料を開いたあと、ビューアの画面に別のリンクをドラッグして落とすと、それを開きます。落とせるのは、マニフェストの URL と、`iiif-content=` の付いたリンクです。いま開いている資料の中の場所を指すリンクなら、そのページに移ります。

## 画面の見方

ビューアの画面は、左の表示欄と、右の説明欄に分かれています。

- 説明欄は、境目をドラッグすると幅を変えられます。ダブルクリックすると元の幅に戻ります。
- 説明欄は、ボタンで閉じたり開いたりできます。スマートフォンでは表示欄の下に出て、高さを変えられます。
- 画面の上の「ダウンロード」は、いま開いているマニフェストのファイルを開きます。
- 画面の上のボタンで、表示の言語（日本語・English）と、明るい表示・暗い表示を切り替えられます。

### 説明欄のタブ

説明欄には、資料の中身に応じてタブが出ます。使える内容が無いタブは出ません。

- **資料情報**: タイトル・説明・メタデータ・提供者・関連リンクなど、マニフェストに書かれた情報です。
- **ページ一覧**: 2 ページ以上ある資料で出ます。サムネイルからページを選んで移れます。
- **目次**: 目次（Range）がある資料で出ます。項目を押すと、そのページや場所に移ります。ページの並べ方が複数あるときは、ここで切り替えます。
- **レイヤー**: 1 つのページに複数の画像が重なっているときに出ます。画像ごとに表示・非表示、重ね順、不透明度を変えられます。画像を順に切り替えて再生することもできます。
- **地図**: 場所の情報を持つ資料で出ます。今のページの場所は赤、ほかの場所は青で示します。地図か一覧の場所を押すと、そのページに移ります。
- **権利**: ライセンスや出典表記が書かれているときに出ます。
- **文字起こし**: 音声・動画に字幕や文字起こしが付いているときに出ます。
- **注釈の文字起こし**: 注釈の形で文字起こしが付いているときに出ます。
- **注釈**: 画像・音声・動画のページに付いた注釈の一覧です。
- **アノテーション**: 3D モデルに付いた注釈の一覧です。語句での検索と、タグでの絞り込みができます。
- **推論**: 画像のページで出ます。画像の文字の読み取りや顔の検出などを、ブラウザの中で行います（後述）。

## 操作のしかた

### 画像

- マウスのホイールで拡大・縮小します。
- ドラッグで、表示する場所を動かします。
- ダブルクリックで、初めの表示に戻ります。
- 1 つのページで画像を選べる資料（Choice）では、切り替えの欄が出ます。「比較」を押すと、2 つを並べて見比べる画面が開きます。

### ページの移動

- 表示欄の「前へ」「次へ」で、ページを移ります。
- キーボードでは、左右の矢印キーで移ります。右から左に読む資料では、向きも逆になります。
- 上下の矢印キーと PageUp・PageDown でも、前後に移ります。
- Home で最初のページ、End で最後のページに移ります。
- キーボードで操作するときは、先に表示欄を一度クリックしてください。

### 3D モデル

- 左ボタンでドラッグすると、モデルを回します。
- ホイールで拡大・縮小します。
- 右ボタンでドラッグすると、表示する場所を平行に動かします。
- スマートフォンでは、1 本の指で回し、2 本の指で拡大・縮小と移動をします。
- 右上の「＋」「−」でも拡大・縮小できます。
- 「回す」を押すと、モデルが自動で回り続けます。「全体」でモデル全体が見える位置に戻り、「上」で真上から見ます。
- マニフェストに視点（カメラ）が書かれていれば、その名前のボタンが出ます。押すとその視点に移ります。
- 動きのあるモデルでは、「動かす」「止める」でアニメーションを再生・停止します。
- 同じ場所に複数のモデルが置かれた資料では、表示するモデルを切り替えられます。「比較」から、2 つを左右に並べたり、スワイプ・スパイグラス・重ね合わせで見比べたりする画面も開けます。

### 音声・動画

- 再生ボタンで再生します。
- 字幕や文字起こしがあれば、説明欄に並べて表示します。
- 複数のメディアを組み合わせたページは、まとめて再生します。

## 注釈（アノテーション）

注釈は、資料の上に重ねて表示します。

- 3D モデルの注釈は、モデルの上の印で示します。印を押すと、その場所に視点が移り、内容が出ます。
- 説明欄の「アノテーション」の一覧から選んでも、その場所に移ります。一覧の欄で、注釈の表示と非表示も切り替えられます。
- 画像の注釈は領域や点として、音声・動画の注釈は時刻として示します。
- 同じ場所に付いた複数の注釈は、まとめて表示します。
- Kasane は注釈を表示するためのビューアです。新しい注釈を書き込んで保存する機能はありません。

## 推論（文字の読み取り・顔の検出など）

「推論」タブでは、表示中の画像を、ブラウザの中で動く機械学習のモデルにかけられます。モデルは次の 4 種類です。

- **文字の読み取り（OCR）**: 文字を行ごとに読み取ります。
  - 「NDL古典籍OCR-Lite」: 古典籍（くずし字を含む）向けです。
  - 「NDLOCR-Lite」: 明治以降の活字の資料（縦書き・横書き）向けです。
  - 「PP-OCRv6」（small・medium）「PP-OCRv5」: 活字の資料（主に横書き）向けです。中国語・英語・日本語に対応します。PP-OCRv6 のほうが新しく、日本語の読み落としが少なくなっています。
    - PP-OCRv6 には small と medium の 2 つの大きさがあります。medium のほうが読み誤りが少なく、small のほうが軽くて速く読めます。
    - 実測では、英語の活字（『不思議の国のアリス』1872 年の版、11 頁）で誤字の割合が small 1.43%・medium 1.35%、漢籍（嘉興蔵、15 面・5,714 字を 1 行ずつ読んだもの）で small 1.65%・medium 1.45% でした。
    - その代わり、medium はファイルが約 139 MB（small は約 31 MB）で、読み取りには 4 倍ほどの時間がかかります（同じ英語の 1 頁で small 5 秒・medium 21 秒）。
  - 「PP-OCRv5（ラテン文字）」: フランス語・ドイツ語・ラテン語などの活字向けです。
- **顔の検出（日本の絵画）**: 浮世絵・絵巻・近代の美人画などに描かれた顔を探して、枠で示します。「顔の輪郭（日本の絵画）」を選ぶと、枠の代わりに顔の形をなぞった輪郭で示します。
- **クリックで切り出す**: 画像の上の物をクリックすると、その形をなぞって輪郭の注釈にします。人物・建物・道具など、何にでも使えます。
- **絵の説明文・物の検出（Florence-2）**: 画像に描かれたものを英語の文章で説明したり、人・動物・建物などを英語の名前付きの枠で示したりします。写真や現代の図版が得意で、古い絵では外すこともあります。

### 使い方

1. モデルを選び、「ダウンロード」を押します。最初の 1 回だけ、モデルをお使いのブラウザに保存します。大きさはモデルによって 10〜360 MB ほどで、ボタンに表示します。要らなくなったら「削除」で消せます。
2. 「この画像で実行」を押すと、画像全体を読みます。「クリックで切り出す」では、代わりに「画像をクリックして切り出す」を押してから、画像の上の物をクリックします。
3. 結果は注釈として、画像に重ねて表示します。注釈の形（JSON）で保存できます。文字の読み取りと絵の説明文の結果は、テキストでも保存できます。

### 拡大した範囲だけを読む

絵巻や大きな地図のような横長・大判の画像は、画像全体を読むと、モデルに渡す前に小さく縮めるため、文字や顔が潰れて見つからないことがあります。そのときは、読みたいところまで拡大してから「表示中の範囲で実行」を押します。見えている範囲だけを切り出して読みます。

- 範囲を移して、もう一度「表示中の範囲で実行」を押すと、結果を前の結果に足していきます。絵巻を場面ごとに読み進められます。
- 「この画像で実行」を押すと、それまでの結果を置き換えます。
- 広すぎる範囲では「表示中の範囲が広すぎます」と出ます。もう少し拡大してから押してください。
- 同じところを 2 回読むと、同じ結果が重なって出ます。

### 注意

画像はどこにも送りません。推論は、すべてブラウザの中で行います。結果は機械による推定で、誤りを含みます。マニフェストの中で切り抜きや回転を指定した画像には、まだ対応していません（ビューアの上で表示を回転させるのはかまいません）。

## そのほかのページ

- [コレクション・キュレーションの検索](../search/): コレクションかキュレーションの URL を入れると、中身をメタデータで絞り込める一覧にします。
- 地図と画像の連携（`/ja/georef/?iiif-content=<URL>`）: 位置の情報（ジオリファレンス）を持つ画像を、地図と並べて表示します。対応点があれば、画像を地図の上に重ねます。
  地図の縮尺と中心（`mapZoom`・`mapLat`・`mapLng`）、画像の拡大率と中心（`zoom`・`centerX`・`centerY`）、画像の回転（`rotation`、度、反時計回りが正）、選んでいる地点（`id`）は、動かすたびに URL に書き込まれます。URL をそのまま渡せば、同じ表示で開けます。引数の名前は IIIF Georeference Viewer（geo.ldas.jp）と同じなので、向こうのリンクの `?` 以降をそのまま使えます（マニフェストを指す `u=` も読みます）。`&lat=<緯度>&lng=<経度>` を足すと、その地点に印を立てて開きます。
  画像は、地点が 2 つ以上あれば、開いたときに北が上になるよう自動で回ります（URL に `rotation` があるときはその角度で開きます）。画像の上の「回転」ボタンから、角度を変える・北を上に戻す・0° に戻すことができます。
  右の一覧は、名前・別名・ID・タグで探せます（カタカナとひらがな、全角と半角は区別しません）。タグがある資料では、検索欄の下のタグを押すと、そのタグの地点だけに絞り込めます。
  地点の付いた画像が 2 枚以上あるマニフェストでは、画像の下の「‹ ›」で切り替えます。見ている画像は URL の `canvas`（Canvas の id、またはマニフェストの何枚目か）に書き込まれます。
  地図の右上では、背景地図（標準・地理院の淡色地図と写真・れきちず）を切り替えられます。地名を入れて検索すると、その場所へ移って印を立てます（OpenStreetMap の Nominatim で検索します）。照準のボタンを押すと、現在地へ移ります（ブラウザが位置情報の許可を求めます）。

## リンクで共有する

ビューアの URL をそのまま人に渡せば、同じ資料を開けます。URL には、開いている資料と、選んでいるタブが入っています。

ページを移っても、URL は変わりません。特定のページを指したいときは、URL の最後に `&canvas=<ページの番号>` を足してください。ページの中の領域や時刻を指したいときは、IIIF Content State を使います（「URL で直接開く」を参照）。

## うまく表示できないとき

### 「マニフェストを読み込めませんでした」と出る

まず、URL が正しいかを確かめてください。ブラウザで URL を直接開き、JSON が表示されるかを見ます。

JSON は表示されるのに Kasane で開けない場合は、CORS の設定が原因のことが多いです。CORS は、他のサイトのページからデータを読むことを許すかどうかの、サーバ側の設定です。Kasane はマニフェストを、お使いのブラウザから直接読みます。マニフェストのサーバが他のサイトからの読み取りを許していないと、ブラウザが読み込みを止めます。この場合は、Kasane の側では直せません。資料の提供元に、CORS の設定をお願いしてください。

### 画像が出ない

画像のサーバが止まっているか、画像の URL が誤っている可能性があります。「この画像はありません」と出るのは、画像を取得できなかったときです。

### ログインを求められる

IIIF の認証（Authorization Flow API 2.0）で守られた画像では、画像の上に「ログイン」の案内が出ます。押すと、提供元のログイン画面が開きます。ログインできて閲覧の権限があれば、画像が表示されます。

- ブラウザが他のサイトの Cookie を制限していると、ログインしても画像が出ないことがあります。
- 認証に対応しているのは画像だけです。音声・動画・3D モデルの認証には対応していません。

### 「この形式の内容は表示できません」と出る

Kasane がまだ扱えない種類の内容です。3D モデルは、GLB 形式と点群に対応しています。

### 推論で「画像を読み込めませんでした」と出る

画像のサーバが、他のサイトからの読み取りを許していない可能性があります。上の CORS と同じ理由です。画像は表示できても、推論には使えないことがあります。
